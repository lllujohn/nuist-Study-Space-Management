# NUIST 自习室管理系统

数据库系统原理课程设计 | MySQL 9.x + FastAPI + Vue 3

## 🌟 项目亮点

除了基础的座位预约和数据看板外，本系统还具备以下“黑科技”特性，满足答辩创新点：
- **🤝 找研友/拼座系统**：预约座位时可打上标签（如“考研高数”），网格图上会闪烁专属图标，鼠标悬浮即可查看暗号，精准结伴自习。
- **🍅 沉浸番茄钟（带严格风控）**：自选 25 分钟全屏专注。首创**双轨制积分规则**（基础时长奖励+番茄钟彩蛋奖励），并在底层严格校验当前预约状态（必须为 Active），彻底堵死“没学习却白嫖积分”的漏洞。
- **🌳 匿名自习树洞**：供大家分享心得、吐槽或寻找失物。支持匿名发布，并且加入了**隐私保护机制**（仅发布者本人可以撤回/删除自己的留言）。
- **💰 完整的信誉分与积分商城体系**：违规自动扣分拉黑，学习时长自动折算积分，积分还能去商城兑换咖啡（支持乐观锁防超发机制）。

## 怎么跑

**1. 初始化数据库**

```bash
mysql -u root -p < init.sql
```

脚本会自动建库（`lingxi_db`），不用手动建。

**2. 改 `.env`**

把 `DB_PASS` 换成自己 MySQL 的密码，`JWT_SECRET` 随便填一个长字符串：

```env
DB_PASS=你的密码
JWT_SECRET=随便一段长字符串
```

**3. 装依赖、启后端**

```bash
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

启动后 http://127.0.0.1:8000 就是系统入口，`/api/docs` 是 Swagger 文档。

## 数据库对象

| 类型 | 名称 | 作用 |
|------|------|------|
| 视图 | `v_room_status` | 实时统计各阅览室空闲/已约/使用中座位数 |
| 视图 | `v_dashboard_stats` | 大屏占座率，给 ECharts 饼图用 |
| 触发器 | `trg_credit_deduct` | 往 credit_logs 插数据后自动扣分，分数跌到 0 以下自动拉黑 |
| 存储过程 | `sp_reserve_seat` | 预约主流程，事务里做完黑名单/冲突检测/写入 |
| 存储过程 | `sp_exchange_product` | 积分兑换，乐观锁（version 字段 CAS）防超卖 |
| 存储过程 | `sp_cleanup_reservations` | 定时清理：爽约 -10 分，暂离超时 -10 分，过期 active 标完成 |
| 定时事件 | `evt_cleanup_reservations` | 每 2 分钟跑一次 sp_cleanup_reservations |

## 常见问题

**启动报 `Access denied`** — 检查 `.env` 里的 `DB_USER` 和 `DB_PASS` 是否正确。

**前端提示连不上后端** — 确认 uvicorn 在 8000 端口跑着，没被防火墙拦。

**`init.sql` 报 `ERROR 1064`** — MySQL 版本需要 ≥ 8.0，用有建库权限的账号执行。
